# Публичная ссылка для жюри — Render

Один бесплатный web-сервис: React, FastAPI и обученные CatBoost-модели. Фронтенд обращается к `/api` на том же домене. База данных и ключи API не нужны.

## Развернуть

1. Откройте [Deploy to Render](https://render.com/deploy?repo=https://github.com/BAITC-Hacks/hack-bacd3af2-sync) и войдите в Render через GitHub. Если репозиторий закрыт, предоставьте Render доступ к нему.
2. Подтвердите Blueprint из ветки `main`. Он создаёт **один сервис `windai`, план Free**. Настройки менять не нужно.
3. Нажмите **Deploy / Apply**, дождитесь статуса **Live** и откройте адрес `https://…onrender.com`, который выдаст Render. Эту ссылку отправляйте жюри.

Если кнопка не открывает Blueprint: Dashboard → New → Blueprint → выберите репозиторий → `main` → `render.yaml` → Deploy.

Настройка занимает несколько минут; первая сборка может занять больше 10 минут. Бесплатный сервис засыпает после 15 минут без запросов, пробуждение занимает около минуты. Перед показом откройте ссылку заранее. У бесплатного тарифа есть месячные лимиты — [условия Render](https://render.com/docs/free).

## Проверить перед отправкой

- Откройте ссылку в режиме инкогнито: интерфейс должен загрузиться.
- Выберите **1 февраля 2026 → обе турбины → 48 ч → «Запустить агента»**. Должны появиться график, сводка, завершённые этапы и объяснение.
- Обновите страницу `/forecast` и откройте `/about`: обе должны работать.
- Откройте `/api/health`: `status` должен быть `ok`. В `/api/metrics` поле `source` должно быть `holdout`.

В Blueprint используется **реальная модель и сохранённый архив прогнозов погоды** за 31 января — 28 февраля 2026. Расчёт не зависит от доступности Open-Meteo. Объяснение формируется по шаблону без платных вызовов LLM. Это те же CatBoost-модели, что в проекте; mock отключён.

Локальный `docker compose up --build` работает как раньше. Для проверки именно облачного образа с установленным Docker:

```bash
docker build -f Dockerfile.render -t windai-render .
docker run --rm -p 10000:10000 -e MODEL_ADAPTER=real -e WEATHER_PROVIDER=archive windai-render
```

Откройте `http://localhost:10000`. Автодеплой отключён, чтобы новые коммиты не перезапускали демонстрацию; обновление запускается через Manual Deploy в Render.
