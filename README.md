# WindAI — прогнозируем чистое завтра

**Ветер меняется. Энергосистеме нужен план.** WindAI прогнозирует мощность двух ветровых турбин на **24–48 часов**: показывает, когда ждать пик и спад, проверяет результат и объясняет его понятным языком. Проект команды **SYNC**, HackAlemAI.

**Реальные измерения → обученные модели CatBoost → прогноз и объяснение в одном интерфейсе.** Модели подключены к backend в `main` и используются по умолчанию.

[![WindAI: прогноз двух турбин, этапы работы агента, погода и объяснение результата](docs/images/windai-dashboard.png)](docs/images/windai-dashboard.png)

Выберите дату, турбины и горизонт — нажмите **«Запустить агента»**. На экране появятся почасовой график, сводка мощности, этапы расчёта и предупреждения. **1 на шкале = 100% номинальной мощности.** Например, 57% в сводке — ожидаемая мощность, а не точность модели.

*На скриншоте блок метрик недоступен; подтверждённые результаты модели — ниже. Изображение открывается в полном размере по клику.*

## Масштаб работы — в цифрах

Для каждой турбины обучена отдельная модель **CatBoost — градиентный бустинг над деревьями решений**. Она рассчитывает мощность по ветру и температуре. Обучение основано на реальных измерениях кейса, а не на mock-данных.

| Что сделано | Результат |
| --- | --- |
| Подготовлены данные | **291 859 исходных записей**, **48 452 почасовых наблюдения** для обучения двух основных моделей за март 2023 — январь 2026. |
| Обучены модели | **Две основные модели по 500 деревьев** и две ранние версии для исторической проверки. [Артефакты и метаданные](ml/models/) |
| Проверено качество | Ошибка примерно **на 29% ниже**, чем у базовой зависимости мощности от ветра. [Сравнение](ml/reports/model_comparison.md) |
| Выполнен архивный прогон | **29 ежедневных запусков**, два горизонта, **4 176 строк прогнозов** на архивной погоде Open-Meteo. [Результаты](ml/reports/february_backtest/README.md) |
| Проверена воспроизводимость | По сохранённому аудиту: **58 ML-тестов**, повторное обучение с совпадением предсказаний, **4 проверки адаптера в памяти**. [Аудит](ml/reports/ml_audit.md) |

Агент получает и проверяет погоду, запускает модель, анализирует прогноз и формирует объяснение. При обнаружении проблем предусмотрены предупреждения и повторный расчёт. Обученные модели включены в Docker-образ; mock включается только явно.

## Насколько точен прогноз

На независимой проверке за **декабрь 2025 — январь 2026** средняя ошибка составила **2,44 и 2,81 процентного пункта номинальной мощности**. Проверяемые модели обучались только на более ранних данных.

<img src="ml/reports/figures/readme_baseline_mae.png" alt="Ошибка CatBoost и трёх базовых подходов для двух турбин: ниже — лучше" width="860">

**Ниже столбец — меньше ошибка.** Золотой цвет — турбина 1, зелёный — турбина 2. Снижение на 29% рассчитано относительно зависимости мощности от ветра; первые два подхода погоду не используют.

<img src="ml/reports/figures/readme_holdout_prediction_vs_actual.png" alt="Фактическая и предсказанная мощность на трёх 48-часовых окнах" width="860">

**Светлая линия — факт, цветной пунктир — модель.** Показаны три фиксированных примера, включая расхождения. Верхний ряд — турбина 1, нижний — турбина 2.

*Условия оценки: использована фактическая погода, поэтому ошибка будущего прогноза погоды в эти метрики не входит. Для февраля прогнозы сохранены, но точность пока не измерена — нет фактической мощности.*

## Открыть локально

Запустите Docker Desktop. В корне проекта выполните:

```bash
docker compose up --build
```

Откройте **[localhost:5173](http://localhost:5173)** → **1 февраля 2026** → **обе турбины** → **48 ч** → **«Запустить агента»**. По умолчанию используются реальные модели; ключ OpenAI не обязателен — без него объяснение формируется по шаблону.
